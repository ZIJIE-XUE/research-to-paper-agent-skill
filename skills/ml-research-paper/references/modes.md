# 模式与按需入口

模式名是 agent 读取的任务意图，不是已安装的 slash command 或独立程序。调用格式：`使用 $ml-research-paper，mode=...，具体任务`。没有明确模式时，从用户目标、当前产物与检查点选择最小必要范围；不要把单阶段任务扩大成全文生成。

## 研究与实验

- **pipeline**：完整推进；读取项目状态、预算与已有授权，按依赖补齐阶段。输出研究稿、证据、复现材料与过程记录。
- **socratic / plan**：宽泛兴趣、关键研究选择不明确时，围绕可回答的问题、证据和资源进行少量高价值追问；输出 `research/brief.md` 与候选取舍。用户要求直接推进时，采用明确记录的合理假设，不要求每阶段重新批准。
- **literature**：搜集、阅读卡、矩阵、反证与研究缺口；读取 `literature-novelty.md`。如果用户已有文献集合，先核验并使用，只为缺口追加搜索。
- **novelty**：六问与最近邻威胁检索；输出有限增量、可证伪实验与创新未确立的可能判定。
- **design**：数据、切分、基线、指标、预算、统计与稳健性协议；读取 `design-execution.md`。没有数据时输出可执行的数据取得计划并说明阻碍。
- **run**：核对已冻结计划、执行环境与剩余预算，调用运行器；缺失的训练入口由 agent 实现并验证。先运行耗时/通路测试，再运行正式队列。不能通过换模式跳过设计或泄漏检查。
- **interpret**：从实际运行产物生成结果汇总、图表计划与主张台账；对探索性分析、统计单位和外推范围作明确标注。

## 写作与核查

- **outline**：只输出章节结构、论证链与图表/证据需求；不编造结果。
- **write**：以已验证材料正式拟稿；证据不足时只写可支持部分并标明缺口。
- **abstract**：基于当前完整稿或已验证结果写摘要，核对问题、方法、样本、关键发现和限制。没有结果时只能生成提案摘要。
- **polish**：润色已有文字，保护事实、公式和支持程度；输出修改稿及编辑记录。
- **citation-check**：检查书目存在、元数据、定位和“主张—来源”支持关系；读取 `integrity.md`，输出 `literature/citation-checks.jsonl` 与可读报告。仅格式检查时可缩小范围，明确未做存在性或支持性核查。
- **integrity**：针对指定版本运行审稿前/交付前完整性检查；输出覆盖数量、阻碍、未知与证据路径。脚本只做结构和追踪核查，语义真实性仍由原文阅读与科学复核支持。
- **format / disclosure**：按照用户指定模板、格式及当前官方政策处理图表、参考文献、AI辅助说明与数据代码声明。先识别实际需要的输出与政策，缺少作者事实不代填。DOCX/PDF需要相应渲染工具；Markdown源稿始终可保留。

## 审稿、修订与恢复

- **review**：默认完整多视角内部模拟审稿；`depth=quick` 做有边界的快速分诊，`focus=methodology` 聚焦方法。先读取当前稿及必要证据，审查期间不直接改稿、不新增实验；输出问题台账、审查结论与修订路线图。快速检查不能标为全面审稿。
- **revise**：将意见按严重度、依赖、成本整理为路线图，再修订；保存旧稿、逐项回应与变更定位。意见也可能有误，允许根据原文和实验有据拒绝。
- **re-review**：先按原问题与验收标准核查修订稿，再看作者回应；输出原问题验收、剩余问题和新引入回归。没有原稿/原意见时明确无法做追踪复审，可改为新一轮审稿并记录。
- **status / resume**：读取并校验检查点、材料护照及交接记录。对陈旧、变更或不完整的产物重新验证；不凭一份历史 PASS 继续。

## 可选能力与边界

系统综述、元分析和大批量盲法筛选需要各自的纳入规则、数据提取、质量控制及适合的统计协议；普通文献搜集不会自动宣称具备这些方法学产出。明确需要时按任务补写协议，或调用用户已有的专门技能并验证交接；本技能未实现 PRISMA 自动计数、RIS 导出或双盲筛选程序。

跨模型核验、多代理协作、参考文献外部索引查询、云计算和文档渲染取决于宿主工具与授权。没有相关工具时执行可用的单代理协议并标明覆盖，不虚构已运行的服务或独立审查。
